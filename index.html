One-Line SDK for Easy Integration

Integrating Quantix analytics into an application requires only a single script tag or npm package. The SDK automatically captures pageviews, clicks, and custom events without requiring extensive configuration [7].

  • The SDK is lightweight, measuring under 4KB gzipped.
  • It offers zero-configuration autocapture for common events.
  • A TypeScript-first API ensures robust and type-safe development.

SDK Implementation Example

Developers can easily track custom events:


// Install: npm i @quantix/sdk

import { Quantix } from '@quantix/sdk'

const qx = new Quantix({
  apiKey: 'qx_live_k8x2...',
  autocapture: true,
  sessionReplay: true,
})

// Track custom events
qx.track('checkout', {
  value: 49.99,
  plan: 'pro'
})

Event tracking is highly efficient, with typical response times of 8ms and a 200 OK status [8].
